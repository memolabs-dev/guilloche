# AspectRatio — kit Guilloche

Conteneur qui conserve un rapport largeur/hauteur.

## Props

| Prop | Défaut | Rôle |
|------|--------|------|
| `ratio` | `16/9` | Valeur CSS `aspect-ratio` |

## Exemple

```twig
<twig:ui:AspectRatio ratio="1/1">
  <img src="/photo.jpg" alt="Description" />
</twig:ui:AspectRatio>
```
