# Separator — kit Guilloche

Trait de separation horizontal ou vertical, avec libelle optionnel.

## Props

| Prop | Défaut | Rôle |
|------|--------|------|
| `orientation` | `horizontal` | `horizontal`, `vertical` |
| `label` | `null` | Libelle centre, avec `aria-label` |

## Exemple

```twig
<twig:ui:Separator />
<twig:ui:Separator label="Ou" />
```
