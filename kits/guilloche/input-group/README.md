# InputGroup — kit Guilloche

Champ avec prefixe ou suffixe, sans perdre l'input natif.

## Props

| Prop | Défaut | Rôle |
|------|--------|------|
| `id` | requis | Identifiant, relie le label |
| `name` | `null` | Nom du champ (defaut : `id`) |
| `type` | `text` | Type HTML |
| `prefix` | `null` | Texte avant le champ |
| `suffix` | `null` | Texte apres le champ |
| `placeholder` | `null` | Texte d'aide |
| `value` | `null` | Valeur initiale |
| `describedBy` | `null` | `aria-describedby` |
| `invalid` | `false` | `aria-invalid` et bordure d'erreur |
| `disabled` | `false` | Desactive le champ |
| `required` | `false` | Champ obligatoire |
