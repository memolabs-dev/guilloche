# ButtonGroup — kit Guilloche

Boutons contigus, avec des coins arrondis aux extremites seulement.

## Props

| Prop | Défaut | Rôle |
|------|--------|------|
| `label` | `null` | Nom accessible du groupe |

## Exemple

```twig
<twig:ui:ButtonGroup label="Alignement">
  <twig:ui:Button appearance="secondary">Gauche</twig:ui:Button>
  <twig:ui:Button appearance="secondary">Centre</twig:ui:Button>
</twig:ui:ButtonGroup>
```
