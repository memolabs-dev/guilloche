# Stat — kit Guilloche

Indicateur chiffre.

## Props

| Prop | Défaut | Rôle |
|------|--------|------|
| `label` | requis | Libelle de l'indicateur |
| `value` | requis | Valeur affichee |
| `hint` | `null` | Precision sous la valeur |
| `trend` | `null` | `up`, `down`, `flat` ; la fleche est decorative |

## Accessibilite

La tendance est aussi portee par la valeur et le `hint` : la fleche seule ne suffit pas.
