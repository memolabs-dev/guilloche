# Timeline — kit Guilloche

Suite d'evenements dates, dans une liste ordonnee.

## Props

| Prop | Défaut | Rôle |
|------|--------|------|
| `items` | `[]` | Evenements `{ date, title, description }` |

## Accessibilite

La liste ordonnee porte la chronologie ; la puce est decorative. Ne pas inverser visuellement l'ordre sans changer le DOM.
