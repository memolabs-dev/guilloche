# Skeleton — kit Guilloche

Forme du contenu attendu pendant un chargement. Purement decorative.

## Props

| Prop | Défaut | Rôle |
|------|--------|------|
| `rows` | `3` | Nombre de lignes simulees |

## Accessibilite

Le composant est `aria-hidden="true"`. L'annonce du chargement doit etre faite par une region `role="status"` de l'application, pas par le squelette.
