# Direction — kit Guilloche

Conteneur avec sens d'ecriture explicite.

## Props

| Prop | Défaut | Rôle |
|------|--------|------|
| `dir` | `rtl` | `rtl` ou `ltr` |

## Usage

Permet de valider une interface en arabe ou en hebreu, ou de rendre une portion de page independante du reste. Les composants du kit utilisent des proprietes logiques (`margin-inline-start`, `inset-inline-end`) quand le sens compte.
